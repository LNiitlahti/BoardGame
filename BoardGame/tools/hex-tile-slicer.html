Hex Tile Slicer Tool

Split a large image into individual hex tiles for the game board

How it works:
1. Upload your main board/texture image - it will be split into 91 hex tiles
2. Optionally upload overlay images for special hex types (these layer on top)
3. Click "Generate Tiles" to preview, then download:

Download options:
• Download Types (4 files) - One file per type: normal.png, mountain-heart.png, side-heart.png, starting-location.png
• Download All 91 - Type files + coords/ folder with all individual tiles named by coordinate (e.g., q0r0.png)

No artwork yet? Click Download Blank Template to get a guide image with the 91 hex extraction boxes outlined in black and labeled by coordinate. Illustrate over it in any art tool, then re-upload it as the Main Board Image (Rotation resets to 0 automatically for you).
